MySQL Connection Guide (For Viva / Lab)

  1. XAMPP Control Panel: Start the MySQL module (port 3306). Default user is root with empty password.
  2. Import Schema: Run schema.sql in phpMyAdmin (http://localhost/phpmyadmin) or MySQL Workbench.
  3. Configure Credentials: Modify db_config.py or create a .env file: 
    MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DB=student_attendance
  4. Auto Fallback: If MySQL is stopped, this system automatically runs on local SQLite without downtime.

Important SQL Queries Used in the Project

1. Attendance Percentage Calculation (Aggregation with GROUP BY & CASE WHEN) 

SELECT 
    s.student_id,
    s.roll_number,
    s.name,
    s.department,
    s.year,
    COUNT(a.attendance_id) AS total_classes,
    SUM(CASE WHEN a.status = 'Present' THEN 1 ELSE 0 END) AS present_count,
    SUM(CASE WHEN a.status = 'Absent' THEN 1 ELSE 0 END) AS absent_count,
    CASE 
        WHEN COUNT(a.attendance_id) = 0 THEN 0.0
        ELSE ROUND((SUM(CASE WHEN a.status = 'Present' THEN 1 ELSE 0 END) * 100.0) / COUNT(a.attendance_id), 2)
    END AS attendance_percentage
FROM students s
LEFT JOIN attendance a ON s.student_id = a.student_id
GROUP BY s.student_id, s.roll_number, s.name, s.department, s.year
ORDER BY s.roll_number ASC;

2. Insert or Update Attendance Batch (Duplicate Prevention via ON DUPLICATE KEY UPDATE) 

INSERT INTO attendance (student_id, attendance_date, status, remarks)
VALUES (%s, %s, %s, %s)
ON DUPLICATE KEY UPDATE 
    status = VALUES(status),
    remarks = VALUES(remarks);

3. Daily Attendance Metrics for Dashboard 

SELECT 
    COUNT(s.student_id) AS total_students,
    SUM(CASE WHEN a.status = 'Present' THEN 1 ELSE 0 END) AS present_today,
    SUM(CASE WHEN a.status = 'Absent' THEN 1 ELSE 0 END) AS absent_today
FROM students s
LEFT JOIN attendance a ON s.student_id = a.student_id AND a.attendance_date = CURRENT_DATE();
